# GitAudit AI

Prototype open source d'audit statique de dépôts GitHub publics, conçu pour démarrer avec **0 € de budget**.

> Projet expérimental : les résultats ne constituent pas un audit de sécurité exhaustif.

## Objectif de la v0.1

- Analyser **sans exécuter** le code des dépôts publics.
- Produire un rapport Markdown lisible avec les constats et leurs limites.
- Utiliser la bibliothèque standard Python et GitHub Actions, sans API d'IA payante.
- Conserver des limites de taille et ne jamais afficher de secrets détectés.

Le développement se fait dans des branches dédiées et via des pull requests. Aucune fonctionnalité commerciale ou paiement n'est activé à ce stade.
