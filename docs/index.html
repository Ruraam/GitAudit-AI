Prototype open source · Audits en lecture seule

Comprendre les risques du code. Sans fausses promesses.

GitAudit AI examine les fichiers de dépôts GitHub publics, classe les indices relevés et prépare des rapports HTML, Markdown et JSON avec des pistes de vérification. Il n’exécute jamais le code du dépôt analysé.

Explorer le dépôt GitHub Voir les audits et rapports

Version expérimentale : cet outil ne certifie pas la sécurité d’un dépôt et peut manquer des problèmes ou signaler de faux positifs. L’analyse publique à la demande par n’importe quel visiteur n’est pas encore disponible.

Comment ça fonctionne

1

Choisir un dépôt

L’exploitant indique un dépôt GitHub public et, si nécessaire, une branche, un tag ou un commit.

2

Examiner sans exécuter

Le programme lit un instantané limité du code et cherche 62 motifs heuristiques couvrant notamment Rust, Python, Go, Java, Dart/Flutter, Lua, SQL, Terraform et Docker.

3

Lire les recommandations

Un rapport HTML autonome explique la nature des indices, une action possible et comment vérifier le résultat.

Obtenir un rapport pour un dépôt

À ce stade, l’exécution manuelle via GitHub Actions est réservée aux personnes autorisées sur le dépôt GitAudit AI. Les visiteurs peuvent consulter le code et les exemples publics, mais pas soumettre librement une analyse depuis cette page.

python3 gitaudit.py Ruraam/BubbleWM --ref feature/wlr-layer-shell --html report.html --report report.md --json report.json

Après analyse, report.html s’ouvre dans un navigateur, même hors ligne. Les rapports ne contiennent pas les extraits de code déclencheurs.
